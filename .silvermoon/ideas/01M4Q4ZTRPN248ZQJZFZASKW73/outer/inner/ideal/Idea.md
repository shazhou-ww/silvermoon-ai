# 建立 tag 触发的 npm 自动发布

## 问题

Connector 已有公开 npm 版本，但缺少统一、可验证的自动发布入口，后续发包仍依赖临时操作。

## 结果

让维护者通过不可变 Git tag 发布经验证的公开包，并用本 idea 持续追踪发布机制及首次真实部署验证。

## 边界

- 参考 Silvermoon 的实际发布方式，只覆盖公开 Connector；保持包可脱离 monorepo 使用，不发布私有包。
- 不给不可信 PR 发布权，不保存 npm 长期凭据；不引入自动版本选择、定时发布或 GitHub Release。
- 本次追踪请求不授权账户配置、创建或推送发布 tag、真实 npm 发布；这些动作须另行明确授权。

## 验收标准

- 合法 tag 能唯一对应包与版本，无效或重复发布指令明确失败。
- 发布前验证实际输出包及独立安装，发布后核对公开版本与包内容。
- 维护者可查阅配置与使用说明，首次真实发布的授权、外部前提和验证结果可追溯；未验证前不宣称部署完成。
