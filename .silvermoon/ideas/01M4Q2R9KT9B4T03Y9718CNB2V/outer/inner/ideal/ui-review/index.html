本轮调整：手机完成 / 恢复应真正联动本机 VS Code，而不是只保存 Relay 标记。

以 VS Code 原生 Done / Restore 的确认结果为准，双向同步。
  • 列表和详情保留小 glyph 与至少 44px 手机点击区；成功意味着本机已确认，而不是请求已收到。
  • 本机手动 Done / Restore 也反映到 Relay；已完成历史从 Show completed 直接读取和恢复。
  • 离线、旧 Connector 和不支持来源禁用；超时显示未确认，不自动重放。
  • 原生 Done 即归档，可能影响原生 worktree生命周期、已读或子项只读；旧 Relay 标记不会批量下发归档。
