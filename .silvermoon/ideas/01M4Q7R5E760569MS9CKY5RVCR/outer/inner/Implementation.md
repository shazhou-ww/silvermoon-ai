# Implementation

## Steps

### I-S01: 复现并统一窄屏回退行为

检查 Settings 入口、消息列表与 Session 详情页的切换状态和响应式布局，记录实际错位原因，复用既有回退模式进行最小修复。

### I-S02: 补充导航回归验证

覆盖窄屏 Settings 返回列表、普通详情页返回、桌面 Settings 和窗口宽度切换；验证焦点、可访问名称以及既有选择与草稿的保持行为。

## Acceptance criteria

### I-AC01: 窄屏返回列表正确

浏览器测试复现原症状并证明修复后返回可见可操作的列表，无 Settings 残留遮挡和横向溢出。

### I-AC02: 既有导航保持一致

定向测试与桌面、窄屏渲染检查证明回退语义与现有详情页一致，桌面导航和 Session 工作状态未受破坏。
