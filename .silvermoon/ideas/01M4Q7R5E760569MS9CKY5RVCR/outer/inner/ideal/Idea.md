# 修复窄屏 Settings 返回消息列表的导航

## 问题

用户报告：移动端 Settings 页面点击左上角消息列表入口后，显示位置不正确。已在 320×640 模拟窄屏复现：当前入口打开覆盖 Settings 的 Sessions 抽屉，而普通 Session 详情页的同位置入口会直接返回完整列表；问题是两处内部导航语义不一致，并非 Settings 卡片横向溢出。

## 结果

移动端或窄屏 Settings 的左上角消息列表入口使用与普通 Session 详情页一致的回退交互，返回可正常浏览的消息列表，而非出现错位或不正确的显示状态。

## 边界

- 复用现有详情页的窄屏回退语义和响应式边界，避免另造导航机制；不以浏览器 history.back 替代产品内部导航而意外离开网站。
- 保持桌面 Settings 导航及既有 Session 选择、筛选和草稿行为，不扩大为 Settings 重设计。
- [UI 变更评审](ui-review/index.html)用于对比窄屏导航决定；该材料仅为说明性评审辅助，不是生产 UI 或规范性行为契约。

## 验收标准

- 窄屏 Settings 的回退按钮外观、可访问名称及返回效果与普通详情页一致。
- 点击后消息列表在正确的位置显示且可操作，Settings 不再遮挡或造成横向溢出；准确错位症状以复现证据为准。
- 桌面导航与窄屏详情页既有回退行为无回归，调整窗口宽度后显示状态仍一致。
