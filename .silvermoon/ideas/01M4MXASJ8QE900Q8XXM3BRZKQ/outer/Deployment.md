# Deployment

尚未授权部署；本文件仅是后续现实世界验证的准备种子，不表示已发布。

## Steps

### D-S01: 部署经批准的 Web 构建

实施 revision 正式验收且用户授权部署后，以现有 Web 发布流程部署构建产物，不改后端登录会话模型。

### D-S02: 验证生产导航与配置

使用受控测试账户验证生产 Settings 路由、身份绑定返回、设备创建和退出当前浏览器流程，不将完整 token 写入证据。

## Acceptance criteria

### D-AC01: 生产路由可直达

生产 `/settings` 直达、刷新及身份绑定返回可用，静态路由回退规则被部署平台实际采用。

### D-AC02: 真实流程与原有鉴权兼容

真实桌面及窄屏中配置导航、设备操作、草稿恢复和 Sign out 可用；原有鉴权、有效期、登录上限及 Session 列表策略未变。
