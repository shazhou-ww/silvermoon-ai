# Deployment

准备阶段轻量初版，构想验收不覆盖本契约。外部操作需进入部署阶段并确认操作范围；本阶段不迁移真实数据库、不发布 connector、不部署服务。

## Steps

### D-S01: 准备兼容升级与恢复条件

明确目标环境、实际迁移、Relay/Web 与 connector 版本及升级顺序；区分仓库同步与包发布，确认备份、恢复条件和发布范围。

### D-S02: 应用外部升级

按已同步的部署契约应用迁移与服务/设备更新，保留历史身份及数据；旧 connector 未确认状态显式提示，不隐式放开操作。

### D-S03: 验证真实离线与重连

在目标设备验证混合列表、断网、重连确认、历史读取、主动继续和未确认结果；记录实际环境、版本与可复核结果，不以 mocked API 或构建代替外部证据。

## Acceptance criteria

### D-AC01: 实际版本与迁移可核对

取得目标数据库迁移和 Relay/Web/connector 版本的外部证据，确认升级顺序及现有身份和历史没有丢失。

### D-AC02: 真设备状态与操作语义正确

通过真实断网与重连记录证明离线仅显示 Offline、旧快照不计数、已打开页面保留、草稿不自动发送；本次连接能力确认后才允许主动操作。

### D-AC03: 失败与兼容路径可理解

记录同步失败、未知结果、旧 connector 和历史读取的实际反馈；核实不自动重发且已有可复核结果正确归属，无法恢复的结果继续明确未知。
