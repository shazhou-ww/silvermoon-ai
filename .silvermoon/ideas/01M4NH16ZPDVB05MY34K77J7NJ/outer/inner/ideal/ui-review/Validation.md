# UI 评审材料验证

本文件只说明构想评审材料可读、可打开；不证明应用实现完成，也不复用同步前实现候选的旧测试结果。

- Before 核对同步后的 Session 列表、计数、视图菜单及离线 composer 判定；原输入请求 UI 没有被替换或故意弱化，只省略不影响本次连接决策的区域。
- 本地入口访问三个场景，另独立打开列表场景；CSS/脚本/链接可用，没有构建步骤或未替换占位符。
- 1440px 桌面并排，390px 窄屏上下排列；逐场景及交互后检查无横向溢出、菜单裁切和 iframe 嵌套滚动，并实际检视桌面入口和精确 390px 的展开菜单截图。
- 验证关键词 AND 状态、facet 不随选中状态归零、离线快捷切 All 保留关键词、查看历史仅显示 Offline、草稿保留及确认/只读发送门槛。包括状态重试和示意发送，不发设备请求。
- 键盘 Enter / Tab / Space / Escape 与场景 Home / End / 方向键可操作；开关与重试后焦点恢复到可见控件。
- 未验证真实移动设备、屏幕阅读器、生产 API 或真实断网时序；产品行为以同世界的构想方向卡为准。
