# 隐藏离线 Sessions，恢复可信的当前工作视图

## 问题

设备离线后，列表与计数仍展示旧的 Running / Needs input / Failed，容易让用户误认为是当前状态。刚重连但尚未同步的快照同样不能代表最新工作。

## 结果

默认聚焦在线工作，离线历史通过原视图菜单和就地入口可查看；搜索、计数、详情及重连保持一致的可信度。见 [UI 评审](./ui-review/index.html)及[业务模型评审](./Business-Data-Model-Review.md)。

## 边界

- Offline 是可达性，不改写执行状态、不删除历史、不推断 agent 停止；不合并在线 Needs Input 输入提示工作。
- 当前执行状态与可继续能力分别确认：元数据历史会话可显示执行状态未知，但确认本次连接允许继续后可由用户主动发送；只读与权限约束不变。
- 掉线不跳页，保留正文、阅读位置和独立草稿；未确认命令保持结果未知，不自动重发。

## 验收标准

- 默认隐藏离线；菜单选项与 Ended / Unavailable 独立，N 遵守关键词和生命周期条件；查看历史仅在 All，离线状态只显示 Offline。
- 列表为关键词 AND 状态，切换状态保留关键词；三类计数分别反映关键词范围内的已确认在线状态，不附带离线快照。
- 重连未确认时不恢复旧执行提示或设备操作；失败和未知明确展示，完整历史同步不阻塞已确认能力，失去访问时不继续呈现正文。
