# 用只读事件流工作区替换 Session 主视图

## 问题

通用事件同步底座已具备，但网站仍围绕 Session，账户用户不能直接浏览各 Connector 的流与事件。

## 结果

用户通过现有登录态查看自己 Connector 的 Stream 历史并实时跟随事件，同时保留账户、设备与 token 管理。

## 边界

- 用只读工作区替换 Session 主界面，按流类型预留内置视图扩展，始终可看原始事件；不加载远程插件，不实现 Supervisor 专用视图、事件编辑或远程命令。见[界面对比](ui-review/index.html)。
- 浏览器使用账户授权，不索取或暴露设备 token；复用 Connector / Stream / Event 身份和日志，不新增业务实体或平行存储。
- 保留旧 Connector/API 兼容与历史，不将旧 Session 自动冒充新流；尚无生产者时如实显示空状态。

## 验收标准

1. 登录用户能按 Connector 浏览流、分页读取与按序号定位事件、查看原始内容并跟随新增事件；视图可按声明类型扩展，未知类型仍可读，界面内存有界。
2. 空、离线、恢复、读取失败和历史缺口可区分；连接在线不冒充业务状态新鲜，断线不静默跳过事件。
3. 账户隔离、登录失效与设备移除有效；现有账户及凭证管理仍可用，桌面、窄屏和键盘操作可完成主流程。
