# 事件流工作区实施初版

准备阶段的可调整初版，不代表已开始实现。基于已完成的通用同步底座，不重做事件存储。

## Steps

### I-S01: 提供账户级只读访问

复用浏览器登录态、账户/设备归属与 DO 日志，提供 Connector 状态、流枚举、事件分页及安全订阅入口；每次读取和持续交付落实撤销、登录失效与设备移除。明确浏览器跨源与会话校验，不向网页交付设备 token，不赋予 writer 权限。

### I-S02: 替换主工作区并保留管理

将 Session 主导航与详情替换为 Connector 分组的 Stream 清单及只读 Event 视图，支持序号定位、原始内容、合法 JSON 格式化、分页和可暂停实时跟随。事件只按文本呈现，不执行 HTML；限制载入条数与字节，旧事件通过显式分页再读。通过带版本的 contentType 匹配内置视图注册接口，保留原始事件入口和明确的组件错误边界；未知类型回到通用视图，不执行来自 payload 的代码或模块 URL。详见[视图扩展边界](Stream-View-Extension.md)。保留账户、设备、token 管理及旧 API，替换相关返回导航和 Session 专属状态文字，不删除旧历史。

### I-S03: 验证状态和迁移兼容

覆盖首次空状态、离线历史、重新连接、权限失效、读取失败、历史缺口与复制失败；设备在线状态从新同步链路获得，不沿用旧 Session 在线事实。检查旧 Session 深链接的明确退役提示或兼容跳转，不静默指向错误流。完成桌面/窄屏、键盘与既有管理回归并更新说明。

## Acceptance criteria

### I-AC01: 浏览与实时跟随正确

通过 API 与真实浏览器测试证明多 Connector、多流、分页、序号定位、暂停/恢复无静默缺口或重复显示；同序号仅在同流内比较，超过 JS 安全整数仍准确。用超过显示上限的数据证明视图内存受载入条数与字节约束，不以无限累积实现跟随。用测试组件证明已知类型可选择扩展视图、未知类型保留原始内容、渲染失败显式可见且仍可切回原始事件；不以测试组件宣称已交付 Supervisor 业务视图。

### I-AC02: 权限和异常显式

用跨账户、伪造设备、跨源订阅、失效会话及移除设备测试证明访问被拒；网页不需要或收到设备 token。浏览器状态测试证明空数据不等于失败、历史不等于在线、断线恢复保留位置，读取/复制失败及历史缺口明确展示。

### I-AC03: 管理与兼容不退化

账户登录、身份绑定、设备增改删、token 创建/轮换/撤销的适用回归通过；旧 Connector/API 继续可用，旧深链接按记录的迁移行为处理。按 UI 评审覆盖桌面、320px 窄屏及键盘，运行仓库适用检查并保留证据。
