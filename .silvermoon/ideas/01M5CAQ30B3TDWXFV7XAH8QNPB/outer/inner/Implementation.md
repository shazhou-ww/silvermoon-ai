# 事件流工作区实施初版

准备阶段的可调整初版，不代表已开始实现。基于已完成的通用同步底座，不重做事件存储。

## Steps

### I-S01: 提供账户级只读访问

复用浏览器登录态、账户/设备归属与 DO 日志，提供 Connector 状态、流枚举、事件分页及安全订阅入口；每次读取和持续交付落实撤销、登录失效与设备移除。明确浏览器跨源与会话校验，不向网页交付设备 token，不赋予 writer 权限。

### I-S02: 替换主工作区并保留管理

保持现有品牌区、顶栏、左右外壳和左侧列表行/搜索/分组的视觉语言，Sessions 换为 Streams；移除不适用的创建 Session 和业务状态操作，不另做导航体系。主要改造右侧为默认事件表格，列为序号、内容预览和查看/复制操作；流身份与范围放在顶栏，完整内容放入独立详情区，合法 JSON 可格式化，未知内容仍按文本显示，不执行 HTML。

事件表格使用真正的虚拟行渲染，固定或受控的预览行高与有限 overscan，完整 payload 不撑高虚拟行。虚拟化与分页、有界缓存分开保证；不先下载所有历史再隐藏 DOM。暂定默认缓存不超过 2,000 条且原始 payload UTF-8 合计不超过 8 MiB，实际事件行 DOM 不超过 200 条（含 overscan）。这不是总 JS heap 上限。支持显式回读已淘汰页、序号定位、跟随/暂停、追加时滚动锚点及键盘焦点；不能为了淘汰缓存移动已处理位置或丢弃未处理订阅。窄屏沿用清单/详情切换，仅减少表格可见列，不引入新的整页结构。

通过带版本的 contentType 匹配内置视图注册接口，保留原始事件入口和组件错误边界；未知类型回到通用表格，不执行来自 payload 的代码或模块 URL。专用视图也遵守数据窗口，不能假定当前载入页就是全部历史。详见[视图扩展边界](Stream-View-Extension.md)。保留账户、设备、token 管理及旧 API，替换相关返回导航和 Session 专属状态文字，不删除旧历史。

### I-S03: 验证状态和迁移兼容

覆盖首次空状态、离线历史、重新连接、权限失效、读取失败、历史缺口与复制失败；设备在线状态从新同步链路获得，不沿用旧 Session 在线事实。检查旧 Session 深链接的明确退役提示或兼容跳转，不静默指向错误流。完成桌面/窄屏、键盘与既有管理回归并更新说明。

## Acceptance criteria

### I-AC01: 浏览与实时跟随正确

通过 API 与真实浏览器测试证明多 Connector、多流、分页、序号定位、暂停/恢复无静默缺口或重复显示；同序号仅在同流内比较，超过 JS 安全整数仍准确。以至少 100,000 条可读取历史的场景验证滚动、跨页定位、连续追加及长 payload：不完整预取历史，事件 DOM 行数始终不超过 200，缓存不超过 2,000 条且原始 payload UTF-8 不超过 8 MiB；实施若调整数值必须同步契约和证明，不能仅以 CSS content-visibility 声称完成虚拟化。检查缓存淘汰后的回读、滚动锚点、选择/展开和键盘焦点，不出现错行或凭空移动消费位置。用测试组件证明已知类型可选择扩展视图、未知类型保留原始内容、渲染失败显式可见且仍可切回原始事件；不以测试组件宣称已交付 Supervisor 业务视图。

### I-AC02: 权限和异常显式

用跨账户、伪造设备、跨源订阅、失效会话及移除设备测试证明访问被拒；网页不需要或收到设备 token。浏览器状态测试证明空数据不等于失败、历史不等于在线、断线恢复保留位置，读取/复制失败及历史缺口明确展示。

### I-AC03: 管理与兼容不退化

账户登录、身份绑定、设备增改删、token 创建/轮换/撤销的适用回归通过；旧 Connector/API 继续可用，旧深链接按记录的迁移行为处理。按 UI 评审证明整体外壳和左侧列表风格延续，变化集中在右侧表格；覆盖桌面、320px 窄屏及键盘，运行仓库适用检查并保留证据。
