# 重连后补齐断线期间的 session 历史

## 问题

connector 断开时，用户仍可在设备上继续与 session 对话；connector 重连后目前只恢复在线状态和 session inventory，没有自动补偿断线窗口内新增的消息，导致 Relay 中的会话历史永久缺段。

## 结果

connector 每次重连后自动核对可见 session 的本地权威历史，将 Relay 尚未持久化的消息和活动补齐，并继续接收实时事件。用户无需手动触发 history sync，即可看到连续且顺序正确的会话。

## 边界

- 补偿与实时事件并发、重复重连或命令重试时必须幂等，不得产生重复、乱序或覆盖更完整事件。
- 只保证补齐设备仍能读取的历史；若本地 session 已删除、被保留策略清理或读取失败，必须显式记录未同步缺口，不能报告为完整。
- 本 idea 不改变消息发送语义，也不承诺跨设备合并同一 session。

## 验收标准

- connector 断开期间产生多轮对话后重连，Relay 自动出现全部漏失事件，顺序与设备历史一致。
- 连续重连、补偿重试以及补偿期间的新实时消息不会产生重复或遗漏。
- 无法读取完整历史时，Relay 保留已有事件并呈现可诊断的部分同步状态。
