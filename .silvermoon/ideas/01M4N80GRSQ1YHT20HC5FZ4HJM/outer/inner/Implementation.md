# Implementation

## Steps

### I-S01: 落实响应式登录布局

按获批评审方案调整未登录页面的信息层级、英文文案和桌面/窄屏布局；大屏使用统一 panel 将整组内容居中，以横向展开的银月长发背影线图平衡左侧登录卡；761–1000px 保持两栏中心线对齐，760px 及以下隐藏线图并自然展开，保持已登录工作区不变。

### I-S02: 接入既有品牌与官方提供商视觉

复用已批准的银月品牌素材，并从 Google、Microsoft、GitHub 官方品牌资源获取本地静态图标，为三种 OAuth 入口提供一致且可访问的视觉标识，不引入新的图片生成。

### I-S03: 完善状态与回归覆盖

让加载和 OAuth 错误状态适配新版登录卡，并补充聚焦登录页关键层级、响应式和可访问行为的回归验证。

## Acceptance criteria

### I-AC01: 界面符合获批方向

浏览器截图或自动化检查证明大屏统一 panel 精确居中、价值点不贴视口底部、背影线图与登录卡视觉重量平衡；过渡宽度两栏中心线对齐，760px 及以下不渲染线图，窄屏层级和配色符合最终 UI 评审材料。

### I-AC02: 认证行为保持正确

自动化测试证明三个入口仍指向各自 OAuth start 地址，首次创建账户和回访登录行为未因界面重构改变，错误提示可见且可重试。

### I-AC03: 质量检查通过

Web 应用的相关测试、类型检查和构建通过，并通过官方图标加载、键盘顺序、可见焦点、可访问名称和无横向溢出检查。
