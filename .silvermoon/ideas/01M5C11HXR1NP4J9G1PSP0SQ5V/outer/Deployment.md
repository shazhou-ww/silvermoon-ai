# 通用事件同步外部验证

本轮外部验证默认使用隔离的 Cloudflare 本地验证环境和真实 Node 协议客户端，不发布 npm 包、不迁移生产数据、不自动部署生产。生产上线须另有明确的交付范围与凭证；不得以本地通过宣称生产可用。

## Steps

### D-S01: 准备隔离验证环境

核对已有 Worker 交付配置与新增 DO 迁移，使用独立本地状态目录启动授权验证环境，准备无敏感数据的测试账户、设备及凭证。记录精确实现版本、启动方式和范围，不复用未知本地数据。

### D-S02: 运行真实生产者与消费者

使用 Node 生产者和消费者经真实 WebSocket 同步多条流，确认持久追加、历史读取、连续订阅和背压。记录脱敏结果，不要求 Supervisor 业务适配或新 UI。

### D-S03: 验证恢复与隔离并清理环境

验证客户端重连和服务进程重启后的补传与历史延续，检查跨账户拒绝、凭证撤销、旧链路可达。完成后停止操作拥有的验证进程，仅清理明确的临时文件。

## Acceptance criteria

### D-AC01: 隔离环境与版本可复现

保存精确实现版本、隔离状态位置、启动和复现命令及脱敏结果；证明运行了实际 Node/Worker/DO 链路，不是静态夹具或仅函数调用。

### D-AC02: 外部故障恢复符合协议

实际中断连接并重启验证服务，记录流身份和事件位置延续、重复不增行、冲突明确失败及订阅可恢复；不存在静默丢失或成功形态降级。

### D-AC03: 隔离兼容与验证收尾成立

在验证环境确认跨账户与撤销拒绝，结合既有 Session 回归证明兼容；验证进程已停止，生产未变更且无 npm 发布。若真实运行或必要身份验证不可用，保留阻塞证据，不记录完成。
