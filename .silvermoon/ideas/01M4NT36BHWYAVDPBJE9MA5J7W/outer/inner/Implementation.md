# Implementation

## Steps

### I-S01: 统一过期时间比较语义

调整 OAuth 有效事务查询，使持久化的 ISO 8601 时间先由 SQLite 解析，再与数据库当前时间比较；保持阈值和事务写入格式不变。

### I-S02: 增加限流回归覆盖

补充同一 UTC 日期内已过期、仍有效和达到十条阈值的测试，覆盖匿名发起者的实际查询路径。

## Acceptance criteria

### I-AC01: 过期事务不再占用名额

自动化测试证明未消费但已过期的事务不会触发 429，并验证未过期事务仍参与计数。

### I-AC02: 阈值行为保持不变

自动化测试证明十条真实有效事务仍返回 `oauth-rate-limit`，未改变既有防刷边界。

### I-AC03: Worker 验证通过

Worker 的目标测试和类型检查通过，证明查询修复未破坏 OAuth 启动流程。
