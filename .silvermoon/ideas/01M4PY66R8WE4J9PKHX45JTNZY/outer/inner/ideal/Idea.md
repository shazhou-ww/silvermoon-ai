# 支持设备重命名与安全移除

## 问题

Devices 只能添加、轮换或撤销 token，无法修正名称或移除退役设备。直接删除现有 Connector 又会连带丢失 Session 历史。

## 结果

用户可以重命名设备，也可以经确认将在线或离线设备从账号移除，同时继续只读查看其已同步历史。

## 边界

- 重命名只改变显示名称，不改变设备身份、连接凭据或 Session 归属；Relay 各处统一显示当前名称。
- 删除不可恢复连接资格：全部关联 token 失效，在线连接断开，旧凭据不能重连或重建设备；重新添加产生新身份，不合并旧历史。
- 保留 Relay 已同步的 Session、事件与命令记录；不清除本机数据，不承诺停止本地 agent 或撤回已发送指令，首版不提供历史彻底清除。

## 验收标准

1. 设备所有者可保存有效新名称或取消，设置、Session 标签、分组、搜索及设备选择一致更新，连接不中断。
2. 删除前明确说明影响；删除后设备不再出现在正常 Devices 列表和可用设备选择中，旧连接及凭据不能继续读写，失败不能伪装成功。
3. 已移除设备的历史保留名称和“已移除”归属，可发现、可只读查看且不可发送；其他设备不受影响。
