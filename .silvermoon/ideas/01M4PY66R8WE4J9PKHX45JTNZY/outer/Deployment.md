# Deployment

## Steps

### D-S01: 准备兼容发布与验证环境

部署阶段确认授权环境、专用测试账号/设备、持久化迁移顺序、前后端兼容和回滚边界。发布或回退均不得重新启用已移除设备的旧凭据；不使用用户真实设备进行破坏性验证。

### D-S02: 发布并验证外部行为

仅在明确部署授权后发布相关组件；用专用在线和离线设备验证重命名、删除、旧 token 重试、只读历史和重新添加，并检查实际 Connector 的断线重试与提示。验证其他设备和已有历史不受影响。

## Acceptance criteria

### D-AC01: 发布与兼容边界可证明

记录实际环境、组件版本、迁移结果及兼容检查，证明现有设备身份、所有权和历史归属保持不变，回滚方案不会复活旧凭据。不得记录 token 明文。

### D-AC02: 用户结果端到端成立

通过专用设备的浏览器操作、Connector 日志及授权的只读数据核对，证明在线/离线设备可移除、旧凭据被拒绝、历史仍可读不可发送、新设备身份独立；保存桌面/窄屏证据，并确认使用说明准确区分 Relay 断开与本地 agent 运行。
