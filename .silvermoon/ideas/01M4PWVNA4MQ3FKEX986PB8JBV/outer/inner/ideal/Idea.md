# 保留 Session 列表视图偏好

## 问题

Session view options 的四个开关仅保存在页面内存中，刷新后全部恢复关闭，用户必须重新选择。

## 结果

刷新或重新打开页面后恢复该账号上次保存的视图偏好；同账号标签页实时同步。菜单布局和筛选含义保持不变。

## 边界

- 仅保存 Show ended、Show unavailable、Show offline Sessions、Group by Device；不保存搜索、状态筛选、Session 选择、分组展开/折叠或草稿。
- 同浏览器、同站点按账号隔离，关闭浏览器后仍保留；退出登录或登录失效不删除，再登录同账号恢复。不涉及服务端或跨设备同步。
- 无记录时沿用四项关闭的默认值；存储读取失败或内容损坏回到默认，写入失败保留当前页选择，并明确提示及记录错误，不阻断列表使用。

## 验收标准

- 四项任意组合刷新后保持；菜单、列表和自定义视图指示一致，离线历史快捷入口的开关变化也被保存。
- 同账号标签页实时反映成功保存的偏好；切换账号不串用，退出后再登录恢复该账号偏好。
- 存储异常可见且列表仍可操作；范围外状态的行为不变。

[UI 对比](ui-review/index.html) 是说明性评审材料，不是生产 UI 或另一个行为契约；本方向卡为规范性来源。
