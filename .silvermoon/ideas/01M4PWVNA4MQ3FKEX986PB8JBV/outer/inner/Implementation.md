# Implementation

本契约落实已验收构想；部署仍留待独立验收和获准交付流程。

## Steps

### I-S01: 接入账号隔离的偏好存储

通过 `session-view-preferences.ts` 的存储函数与 hook，在当前 Web 站点的 `localStorage` 中按编码后的账号 ID 保存版本 1 的四个布尔字段。仅在账号明确后读取，完整校验记录；没有记录沿用全关，损坏或未知版本提示并回退，不在读取时重写数据。错误通过结构化日志和列表既有的内联提示区域呈现，可关闭且不堆叠遮挡窄屏菜单；不复用草稿的会话期限或退出清除策略。

### I-S02: 统一视图变化与标签页同步

菜单和离线历史快捷入口通过同一更新入口保存开关。使用同源 `storage` 事件监听当前账号命名空间，并重读最新记录，避免重放过时事件；忽略其他账号、无关键和 `sessionStorage`，无写回循环。并发写入以最后成功写入的完整组合为准，读取同一结果；失败写入仅保留本页选择。删除记录或清空存储恢复默认。退出、登录失效或账号切换停止旧账号监听并隔离页面快照，不删除已保存偏好。

分组启用或恢复时等设备数据到齐，优先展开当前选择所属的可见分组，否则展开第一个可见分组；只初始化一次，不在后续同步或刷新设备数据时强制重新展开。展开/折叠本身不保存或同步，筛选语义和菜单布局不变。

### I-S03: 验证边界并更新相关说明

补充全部 16 种组合、开启和关闭保存、离线历史快捷入口、账号隔离、重登、多标签页及存储异常测试。运行相关单元、浏览器、类型、lint 和生产构建检查；回归既有登录与草稿流程，在 README 说明作用域和降级边界。实际验证结果记录于 [Evidence.md](Evidence.md)，不将准备阶段的示意 HTML 当作产品验证。

## Acceptance criteria

### I-AC01: 四项恢复与列表一致

浏览器测试证明全部四项开关的组合可跨刷新恢复，首次使用默认全关；离线快捷入口变化会保存，恢复分组后可浏览列表，菜单状态及自定义视图指示正确。

### I-AC02: 账号生命周期与实时同步正确

浏览器测试证明同账号两个标签页同步成功保存的变化，退出与登录失效后记录保留，再登录恢复；切换账号不泄漏或覆盖另一账号偏好，其他浏览器不发生服务端同步。

### I-AC03: 异常可见且不扩大范围

模拟禁用存储、读取/写入异常及损坏内容，证明默认回退或当前页选择保留、可见提示与错误日志存在，列表仍可操作。回归证明搜索、状态筛选、选择、展开/折叠和草稿的既有行为不变，相关检查通过。
