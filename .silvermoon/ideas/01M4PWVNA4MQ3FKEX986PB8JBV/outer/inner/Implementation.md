# Implementation

准备阶段轻量初版，构想验收不包含本契约，实施时再细化。

## Steps

### I-S01: 接入账号隔离的偏好存储

在前端使用持久浏览器存储保存四个布尔偏好，校验读取内容，并在账号明确后恢复。沿用现有前端存储的错误回调、可见提示和结构化日志模式；不复用草稿的会话期限或退出清除策略。

### I-S02: 统一视图变化与标签页同步

覆盖菜单、离线历史快捷入口、恢复和同账号跨标签页同步，保持分组初始展开及列表规则一致。账号切换或登录失效时停止旧账号同步，不覆盖其已保存数据，不持久化范围外状态。

### I-S03: 验证边界并更新相关说明

补充针对组合恢复、账号隔离、并发标签页、存储异常的单元与浏览器测试，运行相关检查，并更新直接相关使用说明。以源码和说明性 UI 对比为回归参照，不改菜单设计。

## Acceptance criteria

### I-AC01: 四项恢复与列表一致

浏览器测试证明全部四项开关的组合可跨刷新恢复，首次使用默认全关；离线快捷入口变化会保存，恢复分组后可浏览列表，菜单状态及自定义视图指示正确。

### I-AC02: 账号生命周期与实时同步正确

浏览器测试证明同账号两个标签页同步成功保存的变化，退出与登录失效后记录保留，再登录恢复；切换账号不泄漏或覆盖另一账号偏好，其他浏览器不发生服务端同步。

### I-AC03: 异常可见且不扩大范围

模拟禁用存储、读取/写入异常及损坏内容，证明默认回退或当前页选择保留、可见提示与错误日志存在，列表仍可操作。回归证明搜索、状态筛选、选择、展开/折叠和草稿的既有行为不变，相关检查通过。
