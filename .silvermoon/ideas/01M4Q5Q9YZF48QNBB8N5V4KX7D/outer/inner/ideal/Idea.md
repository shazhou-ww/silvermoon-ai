# 让 Google、Microsoft 和 GitHub 登录可以切换账号

## 问题

在已有提供商登录状态下，退出 Relay 后再次登录会直接进入原账号，没有提供选择另一账号的机会。Google 流程已有复现，用户补充 Microsoft 和 GitHub 也有同样问题；该问题阻塞了 Session 视图偏好的真实账号隔离验收，见 [复现记录](Reproduction.md)。

## 结果

用户通过 Google、Microsoft 或 GitHub 登录时，可以明确切换到现成的另一个 Relay 账号，而不是被自动带回原账号。

## 边界

- 范围包含 Google、Microsoft、GitHub；区分已有复现和用户补充报告，逐一核实提供商的切换能力，不假定三者使用相同机制。
- 不改变身份绑定、账号合并、权限或账号隔离语义，不为切换自动创建测试账号。
- 本轮仅登记，后续再准备评审和实现；不修改生产代码或部署。

## 验收标准

- 三种提供商分别已有登录状态时，用户仍可明确切换到另一现成账号并进入对应 Relay 账号。
- 取消选择或选择原账号不会误绑定身份或改变账号数据；正常登录仍可用。

## 下一步

后续恢复准备时，确认三种提供商的账号切换交互并按项目 guidance 完成桌面、窄屏流程的 UI 评审；当前不提交构想验收。
