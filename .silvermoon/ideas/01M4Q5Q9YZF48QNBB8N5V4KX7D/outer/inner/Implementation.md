# Implementation

本轮为问题登记，下列内容是可调整的轻量种子，不授权实现。

## Steps

### I-S01: 确认授权流程与账号选择方案

核实 Google 授权参数和现有登录入口；准备阶段使用 ui-change-review 创建说明性评审材料，实际检查桌面、窄屏与取消场景。保留当前身份模型，不引入账号合并或绑定变化。

### I-S02: 实现获准方案并验证登录回归

仅在构想获准后修改必要的登录流程，补充账号选择、原账号登录、取消与安全校验回归覆盖。

## Acceptance criteria

### I-AC01: 选择流程可用且不改变身份语义

通过定向测试与 UI 流程验证证明：已有 Google 登录状态时仍可选择账号，取消可安全返回，原账号登录和身份归属保持正确。

### I-AC02: 既有授权校验保持有效

通过现有和新增定向测试证明 state、PKCE、OIDC 校验及账号权限边界未被放宽；不保存身份、cookie 或凭据到仓库。
