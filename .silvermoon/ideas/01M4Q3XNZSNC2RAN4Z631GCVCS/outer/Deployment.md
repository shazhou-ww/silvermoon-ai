# Deployment

本契约为准备阶段的轻量初版；仅在实施产生外部交付物时细化发布目标与授权。

## Steps

### D-S01: 确认发布与兼容范围

识别受影响的 package、worker 与 Web 交付物，确定协议版本、兼容窗口、发布顺序和恢复路径。

### D-S02: 验证并分阶段发布

先在非生产环境验证新旧组件互操作、重连和历史恢复，再按授权范围分阶段发布；不使用真实 Session 作为默认实验对象。

## Acceptance criteria

### D-AC01: 兼容发布可证明

通过版本化制品、互操作结果和发布记录证明各交付物按约定顺序上线；若没有外部交付物，明确记录不适用及依据。

### D-AC02: 恢复路径可执行

通过非生产恢复演练或等价证据证明失败发布可停止或回退，且不会把不完整历史报告为成功。
