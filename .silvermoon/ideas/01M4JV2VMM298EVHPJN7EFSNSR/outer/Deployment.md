# Deployment

## Steps

### D-S01: 发布 Web 消息流更新

通过现有 Web 部署流程发布已验证的圆形返回控件与消息视口空间调整，不引入新的运行时配置或数据迁移。

### D-S02: 验证线上长会话体验

在生产环境分别以桌面和窄屏视口打开包含足够历史记录的 Session，验证初始定位、历史阅读保护以及右下角圆形返回控件的位置和交互。

## Acceptance criteria

### D-AC01: 线上默认显示最新消息

生产环境长 Session 在桌面和窄屏打开后均显示最新可见事件，并通过带时间的人工 smoke 记录证明。

### D-AC02: 线上返回交互可用

生产环境中向上滚动会在消息列表右下角显示圆形向下箭头控件；新事件不打断历史阅读，激活控件可回到底部，控件不占独立布局行，消息列表底部保持紧凑且不遮挡最后一条消息或输入区，并通过桌面和窄屏检查证明。
